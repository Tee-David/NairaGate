# Code of Conduct

## Our commitment

We want NairaGate to be a welcoming, professional, and constructive open-source project. Contributors and maintainers are expected to treat one another with respect regardless of experience level, background, identity, or viewpoint.

## Expected behavior

Be respectful and specific in technical discussion. Assume good intent while still reviewing code rigorously. Give actionable feedback, accept corrections gracefully, keep discussions relevant to the project, and protect private or sensitive information encountered while contributing.

## Unacceptable behavior

Harassment, threats, discriminatory language, personal attacks, deliberate disruption, publishing another person's private information, or other conduct that would reasonably make participation unsafe is not acceptable.

## Enforcement

Project maintainers may edit or remove comments, commits, code, issues, and other contributions that violate these expectations. Repeated or serious violations may result in temporary or permanent exclusion from project spaces.

Reports should be made privately to the maintainer rather than through a public issue when the report itself contains sensitive information.

## Scope

This code applies in NairaGate project spaces and when someone is representing the project in public spaces.
