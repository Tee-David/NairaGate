## [0.1.0] - Release candidate

### Added

- Framework-agnostic TypeScript client and provider contract
- Paystack provider for Nigerian bank discovery and account resolution
- Strict account and bank-code validation
- Typed domain and provider errors
- Runtime validation for provider response envelopes and payloads
- Endpoint-aware provider error normalization
- Configurable network timeout and injectable fetch boundary
- Deterministic tests for provider behavior, malformed responses, input validation, and error mapping
- Security, architecture, API, getting-started, and contributor documentation
- CI, CodeQL, and dependency automation

This version remains unpublished while final release-readiness checks are completed.
